# Examples

Historical study-phase scripts kept as reference. They demonstrate build123d
techniques (cylinders, slots, parameter blocks) but predate the spec-driven
workflow and may import optional GUI tooling (`ocp_vscode`); they are not
covered by the test suite.

- `bracket_plain.py` — minimal bracket, first build123d exercise
- `bracket_ribbed.py` / `bracket_ribbed_m4.py` — rib-reinforced bracket variants
- `bracket_improved.py` — refined selection and parameterization practice
- `model_1.py` — first parameter-block experiment

For current, spec-driven models see `models/` and [docs/01-workflow.md](../docs/01-workflow.md).
